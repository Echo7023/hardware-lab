# 采购清单

> 目标：用最少的钱把「想法 → 软件 → 电子 → 机械 → 物理现实」这条链路接通。
> 现状：只有 3D 打印这一环就绪，所以先补**能让电路跑起来的最小两件**。
> 原则：一次只买"立刻能用上"的东西；先用起来，再补下一件。
>
> **两件合计预算约 ¥110–320**（万用表 + ESP32 套件）。

---

## 优先级 1：数字万用表

**为什么先买它**：同时解锁 02（焊完能验证焊点）和 03（测量）的一部分。
没有它，焊接就是盲焊——通不通、有没有虚焊，全靠猜。

### 必备功能（收到后照着核对）

- **通断蜂鸣档（continuity）——必须有声音**，这是测虚焊 / 断线的核心功能
- **自动量程 Auto Range** —— 手动量程容易选错档，容易把表烧了
- 直流电压 / 交流电压 / 电阻 / 电流
- 表笔接口是标准 **4mm 香蕉插头**（以后方便换更好的表笔）

### 淘宝搜索关键词

- `数字万用表 自动量程 通断蜂鸣`
- `万用表 数字 高精度 自动量程 防烧`

### 避坑点

- 低端表「看着有通断档但不响」——收到后先用一根导线短接两根表笔，确认有蜂鸣声
- **别把"钳形表"当普通万用表买**：它是夹住导线测电流的，测不了通断和电阻
- **别买"测电笔 / 感应笔"**：那只是测有无火线，不是万用表
- 原装表笔线往往很细、易断，预算够就顺手加一对备用表笔

---

## 优先级 2：ESP32 开发板 + 入门套件

**为什么是 ESP32 而不是 Arduino**：ESP32 自带 Wi-Fi / 蓝牙，一块板子同时覆盖 04（联网）和 06（电机传感器），比"先买 Arduino 再补 ESP32"更省钱。

### 选板子

- 型号：`ESP32-WROOM-32 DevKit`（经典，**38 针**正好是标准面包板宽度）或 `ESP32-S3 DevKitC-1`
- 关键：**必须板载 USB 转串口芯片**（CH340 或 CP2102），否则还要另买 USB-TTL 下载器
- 接口：优先 **USB-C** 版（单位、家里的线都通用）

### 淘宝搜索关键词

- `ESP32 开发板 入门套件 面包板 传感器`
- `ESP32-S3 学习套件 杜邦线 传感器 全套`

### 套件里必须包含（收到后照着点）

- 面包板 830 孔 ×1
- 杜邦线三件套：公对公 20cm、公对母、母对母，各 **≥40 根** —— 这是**免焊**的关键
- LED（红 / 绿 / 黄）+ 限流电阻 220Ω、1kΩ
- 按键开关 ×5
- 传感器：DHT11 或 DHT22（温湿度）、HC-SR04（超声波测距）、光敏电阻、蜂鸣器
- 小电机：SG90 舵机 ×1、直流小电机 ×1 + 驱动模块（L298N 或 TB6612）
- 面包板电源模块或电池盒（电机必须独立供电）

### 避坑点

- **面包板宽度**：38 针的 ESP32 刚好插满标准面包板；30 针窄板两侧引脚会悬空
- **别买成 ESP8266**：更便宜，但单核、GPIO 少，做不了这些练习
- **收到后第一件事**：装 CH340 驱动、确认能连上电脑、上传一个点灯程序——这一步过了再往下
- 电机（舵机 / 直流电机）**不要**从 ESP32 的 3.3V 引脚直接取电，会掉电重启，必须独立供电
- 杜邦线质量差别很大，选"双头镀金"款；线接触不良会让你怀疑自己的代码
- 有的套件配的是 Micro-USB 板子，确认你有对应的线

---

## 后置项（等对应主题真开始再买）

- **焊接耗材**（02 开始时）：练习板 / 洞洞板、助焊剂、吸锡带、元件包 —— 只靠烙铁 + 锡丝，焊不出可验证的电路
- **基本机械工具**（07 开始时）：十字 / 一字螺丝刀、尖嘴钳、斜口钳、美工刀、钢尺、小台钳
- **示波器**（03 深入时）：先别买。等出现"必须看波形"的具体需求再说，入门价位不低
- **树莓派**（05 有具体项目时）：与 ESP32 功能有重叠，别提前买

---

## 下单后立刻做的一件事

东西到货后，先在对应主题目录下记一条：**型号、购买链接、开箱照片**。
照片放 `media/`（本地留存，不进仓库），文字记录正常提交。
这样一个月后你还知道"我到底买的是哪块板子、哪个表"。
