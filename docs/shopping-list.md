# 采购清单

> 目标：用最少的钱把「想法 → 软件 → 电子 → 机械 → 物理现实」这条链路接通。
> 现状（2026-10 更新）：01 已实践；02 / 03 现在就能开工；**唯一真正的缺口是 ESP32 套件**。
> 原则：一次只买"立刻能用上"的东西；先用起来，再补下一件。

---

## 优先级 1（必买）：ESP32 开发板 + 入门套件

**为什么是它**：这是目前唯一挡在 04 / 06 前面的东西。买到手就能同时解锁联网（04）和电机传感器（06）。

**为什么选 ESP32 而不是 Arduino**：ESP32 自带 Wi-Fi / 蓝牙，一块板子覆盖两个主题，比"先买 Arduino 再补 ESP32"更省。

### 买哪种套件

| 档位 | 大致包含 | 适合谁 | 参考价 |
| --- | --- | --- | --- |
| **基础版** | ESP32 板 + 830 孔面包板 + 杜邦线三件套 + LED / 按键 / 电阻 | 只想先把"点灯、读数"跑起来 | ¥40–80 |
| **全套版** | 基础版 + 温湿度 / 超声波 / 光敏 / 蜂鸣器 + SG90 舵机 + 直流电机 + 驱动模块 + OLED | 想一次把 04 和 06 都打通 | ¥100–200 |

> 建议直接买**成套的"ESP32 入门套件"**，别自己单件凑——单件凑容易漏、还更贵。

### 选板子

- 型号：`ESP32-WROOM-32 DevKit`（经典，资料最多，**38 针**正好是标准面包板宽度）或 `ESP32-S3 DevKitC-1`
- 关键：**必须板载 USB 转串口芯片**（CH340 或 CP2102），否则还要另买 USB-TTL 下载器
- 接口：优先 **USB-C** 版（单位、家里的线都通用）

### 淘宝搜索关键词

- `ESP32 开发板 入门套件 面包板 传感器`
- `ESP32-S3 学习套件 杜邦线 传感器 全套`

### 套件里必须包含（收到后照着点）

- 面包板 830 孔 ×1
- 杜邦线三件套：公对公 20cm、公对母、母对母，各 **≥40 根** —— 这是**免焊**的关键
- LED（红 / 绿 / 黄）+ 限流电阻 220Ω、1kΩ
- 按键开关 ×5
- 传感器（全套版）：DHT11 或 DHT22（温湿度）、HC-SR04（超声波测距）、光敏电阻、蜂鸣器
- 小电机（全套版）：SG90 舵机 ×1、直流小电机 ×1 + 驱动模块（L298N 或 TB6612）
- 面包板电源模块或电池盒（电机必须独立供电）

### 避坑点

- **面包板宽度**：38 针的 ESP32 刚好插满标准面包板；30 针窄板两侧引脚会悬空
- **别买成 ESP8266**：更便宜，但单核、GPIO 少，做不了这些练习
- **收到后第一件事**：装 CH340 驱动、确认能连上电脑、上传一个点灯程序——这一步过了再往下
- 电机（舵机 / 直流电机）**不要**从 ESP32 的 3.3V 引脚直接取电，会掉电重启，必须独立供电
- 杜邦线质量差别很大，选"双头镀金"款；线接触不良会让你怀疑自己的代码
- 有的套件配的是 Micro-USB 板子，确认你有对应的线

## 优先级 2（可选）：焊接练习耗材

02 主题现在只差耗材就能开工（烙铁、锡丝、万用表都已有）。想动手练焊点时再买：

- 练习板 / 洞洞板 ×2
- 助焊剂（或助焊笔）、吸锡带
- 一包直插元件（电阻 / LED / 排针 / 电容）

**淘宝搜索关键词**：`洞洞板 练习板 焊接套装`、`助焊剂 吸锡带 套装`
**参考价**：¥30–60

> 提醒：面包板 + 杜邦线（优先级 1 的套件里就有）能让电路**全程免焊**。焊接只在需要长期固定时才上，不必一开始就练。

## 无需购买

- **数字万用表** —— 已有（前两天刚用过），03 主题入门够用。

## 后置项（等对应主题真开始再买）

- **基本机械工具**（07 开始时）：十字 / 一字螺丝刀、尖嘴钳、斜口钳、美工刀、钢尺、小台钳
- **示波器**（03 深入时）：先别买。等出现"必须看波形"的具体需求再说，入门价位不低
- **树莓派**（05 有具体项目时）：与 ESP32 功能有重叠，别提前买

## 下单后立刻做的一件事

东西到货后，在对应主题目录下记一条：**型号、购买链接、开箱照片**。
照片放 `media/`（本地留存，不进仓库），文字记录正常提交。
这样一个月后你还知道"我到底买的是哪块板子"。
