## ✅ 本次下单（唯一必买）

### ESP32 全套套件（36 件）— ¥150–250

**为什么就买它**：你现在唯一的空白是 MCU 本体 + 免焊面包板 + 传感器矩阵，
套件一次补齐，比单件凑更省心（单件凑容易漏、还更贵）。

**买之前跟客服确认两件事**

- [ ] 开发板是 **30 针还是 38 针**？（两者都能插面包板、功能无差别，30 针少几个 GPIO，入门够用；确认一下更稳）
- [ ] **板载 USB 芯片**是 CH340 还是 CP2102；**有没有附 USB 数据线**（套件清单里没有这一项，到货第一晚最容易卡这里）

**会重复的部分**（不用纠结，多一份备份不亏）

- 步进电机 5V + 驱动板 → 你已有 TB6612FNG + JGB37-520
- MG90S 舵机、杜邦线（你已有各 30 根）

**它仍然缺的**

- DHT11 / DHT22 温湿度传感器（只有 LM35 模拟温度）→ 想练温湿度再补，约 ¥5
- 面包板电源模块 → 见下方"关于电池"

**到货后照单核对**

- [ ] 面包板 830 孔 ×1
- [ ] 杜邦线三件套（补充用）
- [ ] LED 盒 + 电阻包 30 种 600 只（含 220Ω / 1kΩ）
- [ ] 传感器：LM35 温度、光敏电阻、HC-SR04 超声波、HC-SR501 人体红外、3144 霍尔、干簧管、SW-420 震动、SW-520D 倾斜、声音
- [ ] 蜂鸣器（有源 + 无源各 1）
- [ ] 显示：OLED 0.96"（I2C）、LCD1602、4 位 / 1 位共阴数码管、8×8 LED 点阵、240×240 彩屏
- [ ] 其他：继电器模块、双轴摇杆、矩阵键盘、21 键红外遥控 + 接收头、MAX98357 音频功放、收纳盒

## 关于"电池" —— 不用买 18650

套件里**没有电源模块**，但你也**不需要靠它才能开始**：

- **90% 的实验用电脑 USB 供电就够了**（点灯、读数、传感器、屏幕全都能跑）
- 只有**给电机 / 舵机独立供电**时，才需要一个独立 5V 电源
- 最省事方案：买一个 **面包板电源模块 MB102（约 ¥5–10）**，电源用你已有的**手机充电宝**（USB 5V）
  —— 比买 18650 + 电池盒简单得多。你的 6V 电机用 5V 跑只会稍慢，不影响练习
- 你已有的那个 2-3S 充电模块，等以后有电池了再启用
