- [ ] 面包板 830 孔 ×1

- 练习板 / 洞洞板 ×2
- 一包直插元件（电阻 / LED / 排针 / 电容）
- 助焊剂（或助焊笔）、吸锡带

**淘宝搜索关键词**：`洞洞板 练习板 焊接套装`、`助焊剂 吸锡带 套装`

- [ ] 套件里**有没有 USB 数据线**（很多套件不带，或配的是只能充电的线）

## 避坑点（下单前扫一眼）

**ESP32 相关**

- **30 针还是 38 针？** 两者都能插标准面包板，脚位都落在 0.1 英寸网格上，**功能上没区别**；30 针少几个 GPIO，入门完全够用。下单前跟客服确认一下针数更稳
- **别买成 ESP8266**：更便宜，但单核、GPIO 少，做不了这些练习
- **别自己单件凑**：单件凑容易漏、还更贵，直接买成套的"入门套件"
- **收到后第一件事**：装 CH340 驱动 → 确认能连上电脑 → 上传一个点灯程序。这一步过了再往下
- 电机（舵机 / 直流电机）**不要**从 ESP32 的 3.3V 引脚直接取电，会掉电重启，必须独立供电
- 杜邦线质量差别很大，选"双头镀金"款；线接触不良会让你怀疑自己的代码

**焊接相关**

- 你已有电烙铁、锡丝、万用表，缺的只有练习耗材 —— 别重复买烙铁
- 练习板的作用是"焊坏不心疼"；先在废板上练手感，再上真东西
- 面包板 + 杜邦线（套件里就有）能让电路**全程免焊**，焊接只在需要长期固定时才上
