## 3. 店家资料评估：哪些值得用、哪些别装

### 值得用

| 资料 | 为什么值得 |
| --- | --- |
| `测试程序\Arduino例程\`（编号 01–23，**没有 11 号**） | 与套件零件基本一一对应，逐条命中 04 的学习目标（GPIO / 按键 / PWM / ADC / I2C / SPI / 中断 / Wi-Fi）；每个 `.ino` 顶部带 GeeksMan 在线文档链接，是「边做边看讲解」的现成路线 |
| `测试程序\MicroPython例程\`（26 个） | 另一条路线，**需先刷 MicroPython 固件**才能用；建议先走 Arduino，暂不刷 |
| `ESP32开发板资料\ESP32资料文档\` | `esp32管脚清单.pdf` + `esp_wroom_32_datasheet_cn.pdf` —— 引脚权威查询，正好补上 04 缺的引脚表 |
| `ESP32开发板资料\esp32蓝牙使用教程\` | 蓝牙控制 LED 的 docx + 手机端 `HCbluetooth.apk` |
| `点亮0.96寸oled屏程序\esp32_oled\` | `esp32_oled.ino` + SSD1306 库 zip；装库按同目录 `安装头文件.txt`：项目 → 包含库 → 添加 .ZIP 库 |

### 别装 / 别被带跑

| 资料 | 结论 |
| --- | --- |
| `开发软件\arduino-1.8.19-windows.exe` | **不装**。已装 IDE 2.x + 核心 3.3.12；esp32 3.x 核心按 IDE 2.x 走，装上旧 IDE 只会多一份混乱。留着当逃生舱即可 |
| `串口驱动\` | **不用下载**。里面是百度网盘链接 + 官网备选；本机 CH340 驱动已装并核实过 |
| `开发软件\Arduino IDE搭建…（附离线安装包）.docx` | 内容是环境搭建教程，推荐的镜像是 **arduino.me 离线包 / `dl.espressif.com`** —— 可作**第二条镜像路**：家里电脑若也遇到 GitHub 超时，改用它更省事（直接下离线 exe 双击装），不必再折腾 jihulab 索引 |

### 用的时候会踩的坑

| 坑 | 说明 |
| --- | --- |
| 例程里的 Wi-Fi 名 / 密码是作者的 | `13.Wi-Fi 连接`、`14.发送网络请求` 里写的是 `GeeksMan / 123456qq.` → **必须改成自己的**，否则一直连不上，还容易误判成板子坏了 |
| `09.SPI 控制 OLED` 的 5 个例子是 **PlatformIO 工程** | 目录里有 `platformio.ini` + `src/include/lib/test`，**Arduino IDE 打不开也编不了**。要练 OLED 直接用 `点亮0.96寸oled屏程序\esp32_oled\esp32_oled.ino`（I2C，SDA=21 / SCL=22） |
| 得先装几个第三方库 | 否则编译报「找不到 xxx.h」：LCD1602 → `LiquidCrystal_I2C`；舵机 → `ESP32Servo`；ULN2003 步进电机 → `CheapStepper`；网络请求 → `ArduinoJson`。都在 IDE「库管理器」里搜名字装 |
| 例程只覆盖套件的一部分 | 例程覆盖：LED / 数码管 / 按键 / 蜂鸣器 / 摇杆 / 矩阵键盘 / 继电器 / 舵机 / 步进电机 / OLED / LCD1602 / LED 点阵 / SD 卡 / RTC / Wi-Fi / 网络请求。**没覆盖**：HC-SR04 超声波、HC-SR501 人体红外、3144 霍尔、干簧管、SW-420 震动、SW-520D 倾斜、声音传感器、红外遥控、240×240 彩屏、MAX98357 音频。其中数字量传感器（霍尔 / 干簧管 / 震动 / 倾斜 / 人体红外）和模拟量（声音）可直接迁移 05 / 07 / 10 号例程；超声波要 `pulseIn`、红外要 `IRremote` 库、彩屏要 `TFT_eSPI`，需另找资料 |
| 附加开发板管理器网址别乱堆 | 四个源里只有两条真能提供 esp32 核心：官方（最新 `3.3.12`，不带 `-cn`）与 jihulab 镜像（最高 `3.3.10-cn`）；`arduino.me/packages/esp32.json` 最高只到 `3.2.1-cn`、`esp8266.json` 与 ESP32 无关 → 后两条已删。**已装的 3.3.12 只存在于官方索引里**，所以不要在开发板管理器里对 `esp32` 点「移除」 |

### 换电脑开工前先看这三条

1. 固件**从未成功烧入过**，芯片是空片 —— 所以"程序配置烧板"已被排除，不用重查。
2. 最可能死因：**5V 电源错一个针位 → 反接**。这块板上排针序是 `GND, VCC, GND, P55, VCC…`，**第一脚是 GND 不是 VCC**。
3. 重启第一步是**买 2 块新核心板 + 加反接保护 + 先限流上电**，不是直接插上通电。
