# 学习路线

核心目标：培养把**一个想法**从脑海一路推到**物理现实**的能力。

```text
想法 → 软件 → 电子 → 机械 → 物理现实
```

## 一条可执行的循环

1. **设计** —— 想清楚要做什么，用 CAD 建模
2. **制造** —— 3D 打印或机械加工出零件
3. **连接** —— 接电子元件、焊线
4. **编程** —— 写固件，让代码驱动硬件
5. **测量** —— 用万用表 / 示波器找出问题
6. **重建** —— 迭代改进，再跑一遍

每做一个项目，真正收获的不是成品本身，而是**更好的直觉**。几年后，你会拥有一整条从想法到实体的能力链，而非只是一个工作台。

## 就绪度与推进顺序

**只做 01 是不够的。** 3D 打印只覆盖「机械」这一环，链路的「电子 + 编程」会断掉，最后只会得到一个漂亮的外壳。

所以补件的目标不是凑齐 7 个主题，而是**用最少的钱把链路接通**：

1. **万用表**（几十块）—— 同时解锁 02 的「焊完能验证」和 03 的一半。
   没有它，焊接就是盲焊：焊点通不通、有没有虚焊，全靠猜。
2. **开发板入门套件**（含面包板 + 杜邦线 + 传感器 + 小电机）—— 一次解锁 04 和 06。
   面包板 + 杜邦线让电路**全程免焊**，焊接留到需要长期固定时再上。

具体型号与避坑点见 [shopping-list.md](shopping-list.md)。

## 使用建议

- 最终目标是**「制造 + 电子 + 编程」三件套同步练**，因为一个完整项目往往三者都要。但当前设备只覆盖「制造」，所以先把 01 跑顺，电子与编程随补件逐步加入。
- 每个阶段的目标清单（Checklist）写在各主题目录的 `README.md` 里，完成后勾选。
- 每做完一个东西，写一段复盘：哪里卡住、怎么解决的、下次怎么更快。
