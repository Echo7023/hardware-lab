# 学习路线

核心目标：培养把**一个想法**从脑海一路推到**物理现实**的能力。

```text
想法 → 软件 → 电子 → 机械 → 物理现实
```

## 一条可执行的循环

1. **设计** —— 想清楚要做什么，用 CAD 建模
2. **制造** —— 3D 打印或机械加工出零件
3. **连接** —— 接电子元件、焊线
4. **编程** —— 写固件，让代码驱动硬件
5. **测量** —— 用万用表 / 示波器找出问题
6. **重建** —— 迭代改进，再跑一遍

每做一个项目，真正收获的不是成品本身，而是**更好的直觉**。几年后，你会拥有一整条从想法到实体的能力链，而非只是一个工作台。

## 就绪度与推进顺序

**只做 01 是不够的。** 3D 打印只覆盖「机械」这一环，链路的「电子 + 编程」会断掉，最后只会得到一个漂亮的外壳。

好消息是缺口比想象的小（2026-10 盘点后）：

- **01** 已实践过（理线盒），待补的是**切片参数调整** —— 层高、支撑、填充、速度、温度、首层附着。
- **02 / 03 器材已经齐全**：烙铁 + 锡丝 + 万用表 + 洞洞板 + 飞线 + 排针 + 按键，焊接练习立刻能开工。
- **04 / 06 只差一块 MCU**：电机、驱动板（TB6612FNG）、按键都已具备，买一块 ESP32 开发板即可解锁。

所以节奏是：**一边用 02 在洞洞板上练焊点，一边等 ESP32 到货**，不必串行等待。

具体型号与避坑点见 [shopping-list.md](shopping-list.md)。

## 使用建议

- 最终目标是**「制造 + 电子 + 编程」三件套同步练**，因为一个完整项目往往三者都要。「制造」已实践、「电子 / 测量」现在可开工、「编程」等 ESP32 到货就能加入。
- 每个阶段的目标清单（Checklist）写在各主题目录的 `README.md` 里，完成后勾选。
- 每做完一个东西，写一段复盘：哪里卡住、怎么解决的、下次怎么更快。
