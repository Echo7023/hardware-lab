## 就绪度小结

- **已实践**：[01](../01-cad-3d-printing/) —— 已建模并打印过桌面下理线盒，以及大量他人分享的模型。待补的是**切片参数调整**。
- **现在就能开工**：[02](../02-soldering/)（烙铁 + 锡丝 + 万用表，只缺练习耗材）、[03](../03-measurement/)（万用表够入门用）。
- **补一件即可解锁**：[04](../04-arduino-esp32/) / [06](../06-motors-sensors/) —— 靠 ESP32 套件，**这是目前唯一真正的缺口**。
- **暂缓**：[05](../05-raspberry-pi/)、[07](../07-mechanical-tools/)、示波器 —— 等有明确需求再补，避免买了吃灰。
