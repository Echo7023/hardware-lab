# 04 · Arduino 与 ESP32

**对应工具**：Arduino + ESP32
**核心价值**：让代码触及物理世界 —— 用程序驱动真实的电子元件。

## 学习目标

- [ ] GPIO：点亮第一颗 LED
- [ ] 数字输入输出、按键、PWM
- [ ] 模拟输入：读取电位器、光敏等
- [ ] 串口通信与调试打印
- [ ] 总线：I2C / SPI 接传感器与屏幕
- [ ] ESP32：Wi-Fi / 蓝牙，做一个联网小玩意

## 笔记与素材

- 代码放到本项目下的 `firmware/` 或 `code/`
- 笔记放到 `notes/`
- 照片、视频放到 `media/`（只留本地，不进仓库）
