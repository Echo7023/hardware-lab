# 01 · CAD 与 3D 打印

**对应工具**：3D 打印机
**核心价值**：把 CAD 设计转化为实体零件 —— 让画出来的东西变成手里能摸到的东西。

## 学习目标

- [ ] 掌握一款 CAD 建模软件（Tinkercad / FreeCAD / Fusion 360 任选其一）
- [ ] 会导出可打印格式（STL / 3MF）
- [ ] 会用切片软件（Cura / PrusaSlicer / Bambu Studio）
- [ ] 成功打印出第一件小零件
- [ ] 理解常见参数：层高、支撑、填充、材料（PLA / PETG）
