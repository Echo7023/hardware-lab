# 01 · CAD 与 3D 打印

**对应工具**：3D 打印机
**核心价值**：把 CAD 设计转化为实体零件 —— 让画出来的东西变成手里能摸到的东西。

## 学习目标

- [x] 掌握一款 CAD 建模软件 —— 已建模并打印出桌面下理线盒
- [x] 会导出可打印格式（STL / 3MF）
- [x] 会用切片软件 —— 已完成切片并实际打印
- [x] 成功打印出第一件小零件 —— 理线盒，以及大量他人分享的模型
- [ ] **待补：切片参数怎么调** —— 层高、支撑、填充密度、速度、温度、首层附着；自评这是目前最生疏的一环
- [ ] 理解材料差异：PLA / PETG 的特性与适用场景
