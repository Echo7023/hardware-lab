# 项目区

这里用于存放**具体的作品项目**。学习主题（`01-` ~ `07-`）继续按能力组织内容；
做过的实际作品在这里按项目登记。

## 项目列表

| 编号 | 项目 | 状态 | 入口 |
| --- | --- | --- | --- |

| 02 | 电气玩具（卷轴式打磨装置） | **暂停待重启**：硬件已焊完，主控芯片烧毁 | [02-electric-toy](02-electric-toy/) |

> **存放约定**：项目文件直接放在本仓库（单仓库），跨设备只需 `pull` / `push` 一次；
> 媒体素材放各项目的 `media/`（不入库）。已并入的项目，其原独立仓库冻结为只读归档。

## 约定

每个项目一个文件夹：

```text
projects/<项目名>/
├── README.md     # 目标、状态、进度、踩坑复盘
├── cad/          # 3D 模型 / CAD 源文件
├── firmware/     # 固件 / 嵌入式代码
├── bom.md        # 物料清单
└── media/        # 照片、视频记录
```

新建项目时可参考 [templates/project-template.md](../templates/project-template.md)。
