# 项目区（预留）

这里用于存放**具体的作品项目**。目前先按学习主题（`01-` ~ `07-`）组织内容；
等真正开始做项目后，再切换到「按项目」的组织方式。

## 将来的约定

每个项目一个文件夹：

```text
projects/<项目名>/
├── README.md     # 目标、状态、进度、踩坑复盘
├── cad/          # 3D 模型 / CAD 源文件
├── firmware/     # 固件 / 嵌入式代码
├── bom.md        # 物料清单
└── media/        # 照片、视频记录
```

新建项目时可参考 [templates/project-template.md](../templates/project-template.md)。
