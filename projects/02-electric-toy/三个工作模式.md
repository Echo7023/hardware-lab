# 电气玩具 · 三个工作模式

> 整理日期：2026-10-14
> 依据：`05-软件代码/main_sdcc.c`（当前固件，主频 24MHz）
> **一句话**：三个模式共用同一套闭环控制，唯一的区别是「到位之后，下一个目标怎么产生」。

---

## 一、模式切换

模式键每按一下进一档，循环：

```
待机(0) → ±5cm 往复(1) → ±2cm 往复(2) → 随机折返(3) → 待机(0) → …
```

- 开机默认进入 **待机**，电机不转
- 按键 30ms 去抖，按住不连发（按一次只切一档）
- 任何模式下按模式键切走，都会**先停电机**再进新模式
- 电机堵转保护触发后，**按一下模式键即可恢复**

---

## 二、三个模式共用的底座

### 1. 零位
开机瞬间的位置就是本轮**零位（pos = 0）**。所有 ±5cm / ±2cm 都是**相对开机点**，不是机械绝对位置。

### 2. 闭环（每 10ms 一次）
```
误差 err = 目标位置 - 当前位置
```
- **死区 0.3cm（49 脉冲）**：|err| ≤ 49 就判定"到位"
- **软区 1.5cm（249 脉冲）**：距目标 1.5cm 内，按剩余距离**线性减速**（防冲过头）
- **硬限位双保险**：只要 pos ≥ +830 或 ≤ −830，无条件停止朝边界外驱动 —— 任何模式都不许越出 ±5cm

### 3. 滑条调速（统一速度来源）
滑条 ADC（0-1023）→ 占空比 **0~80%**（上限 80% 保护 6V 电机跑 7.4V）。三个模式共用，滑条推得快，整套动作就快。

| 滑条位置 | 占空比 | 电机转速 |
|---------|-------|---------|
| 最左 | 0% | 停 |
| 1/4 | 约 20% | 约 25 RPM |
| 中间 | 约 40% | 约 50 RPM |
| 3/4 | 约 60% | 约 75 RPM |
| 最右 | 80% | 约 90-100 RPM |

### 4. 软启动
占空比按 **1%/ms 爬升**，换向或重启动时清零重爬，抑制电流冲击。

### 5. 位式控制，不用 PID
距目标远就跑满、近了就减速，没有积分/微分环节。

---

## 三、模式 1 · ±5cm 往复（M5）

- 进入时目标设为 **+5cm**，纱布架先朝正方向走
- 到位（|err| ≤ 死区）→ 目标翻成 **−5cm** → 到位 → 翻回 **+5cm**，如此往复
- **单程 10cm**，行程最长、覆盖整根圆柱
- 是项目的主打磨模式

**特点**：两点固定往复，路径规律。长时间使用会在同一处磨出固定纹路。

---

## 四、模式 2 · ±2cm 往复（M2）

- 逻辑与模式 1 **完全相同**，只是把边界从 ±5cm 换成 ±2cm
- 进入时先朝 **+2cm** 走，之后 +2 → −2 → +2 往复
- **单程 4cm**，只在柱头附近集中磨

**特点**：与模式 1 同样是两点往复，区别是范围小、切换更快（距离短，到位更频繁），适合局部精修。

---

## 五、模式 3 · 随机折返（MRAND）

- 进入时先摇一个随机目标，之后**每次到位都重摇一个新目标**
- 目标范围：**±4.7cm**（±5cm 再留出 0.3cm 死区，保证不贴边）
- 约束：新目标与当前位置**至少相隔 0.6cm**（2×死区）才接受，否则重摇（最多摇 16 次）——避免在原地小幅空蹭
- 每一步的方向、距离都不同，轨迹无规律

**运行表现**：
- 纱布架东一段、西一段地走，**每次停的位置和走的长度都不一样**
- 有时几乎横跨全程，有时只在中间晃两下
- 换向前都会先减速、停一拍再反向，不会硬掉头
- 始终限制在约 10cm 范围内，永远不越界

**与模式 1 的关键差别**：模式 1 是"这头 ↔ 那头"两点往复，容易磨出规律沟纹；模式 3 每停一次就换落脚点，**打磨痕迹是散开的、更均匀**。

> 注意：早期文档《工作逻辑》里写的"必须跨越零位""相邻两次方向必须相反"这两条约束，**当前固件并未实现**——代码里只做了范围限制和最小间距限制。

## 六、参数总表

| 参数 | 值 | 含义 |
|------|-----|------|
| `PULSES_PER_CM` | **166** | 脉冲当量（脉冲/cm） |
| `BOUND5` | 830 | ±5cm 边界 / 模式 1 目标（脉冲） |
| `BOUND2` | 332 | ±2cm 目标（模式 2） |
| `DEADZONE` | 49 | 死区 0.3cm |
| `SOFTZONE` | 249 | 软区 1.5cm |
| `RAND_SPAN` | 1661 | 随机目标总跨度 |
| `DUTY_MAX` | 80 | 滑条最大占空比 % |
| `MOVE_MIN` | 20 | 软区减速下限 %（低于此值电机可能转不动） |
| `STALL_MS` | 5000 | 堵转判定时间 5s |
| `STALL_MIN_DUTY` | 20 | 滑条 ≥20% 才启用堵转判定 |
| `PWM_PERIOD` | 1200 | 20kHz @24MHz |

**脉冲当量推导**：编码器 11 线 × 双边沿（×2）× 减速比 56 = **1232 脉冲/电机输出圈** → 卷轴 1232 × 22/26 ≈ **1042 脉冲/卷轴圈** → 卷轴筒 Ø20，周长 π×2.0 ≈ 6.28cm → 1042 / 6.28 ≈ **166 脉冲/cm**。

> 校准方法：跑一次 ±5cm 模式，用尺量纱布实际走了多少。若实际只走 4cm，则把 166 改成 166×5/4 ≈ **208**。

## 七、按键与异常处理

| 事件 | 处理 |
|------|------|
| 短按模式键 | 循环切换模式（30ms 去抖） |
| 长按模式键 | 无动作 |
| 电机堵转（通电但 5 秒无脉冲） | 自动停机，按模式键恢复 |
| 编码器断线（电机转但计数不变） | 表现为等同堵转，5 秒后保护停机 |
| 电池低压 | 由 2S 保护板硬件断电，软件不处理 |
| 方向与预期相反 | 把固件 `INT0_ISR` / `INT1_ISR` 里的 `++` / `--` 对调 |

## 八、执行时序（主循环）

| 周期 | 任务 |
|------|------|
| 1ms | 系统节拍 + PWM 相位翻转 + 占空比斜坡 `ramp_task` |
| 10ms | 读滑条 `duty_slider_task` → 扫按键 `button_task` → 闭环控制 `control_task` |
| 100ms | 堵转检测 `stall_task` |

## 九、快速对照

| | 模式 1 | 模式 2 | 模式 3 |
|---|---|---|---|
| 行程 | ±5cm（单程 10cm） | ±2cm（单程 4cm） | ±4.7cm 内随机 |
| 轨迹 | 两点往复 | 两点往复 | 随机折返 |
| 到位后下一个目标 | 翻成反向边界 | 翻成反向边界 | 重摇随机点 |
| 主要用途 | 整根圆柱打磨 | 柱头局部精修 | 追求均匀无纹路 |
