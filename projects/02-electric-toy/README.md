## 为什么会烧 —— 根因分析

### 现场还原（2026-10-21 用户补充）

> 所有元件焊完，只差烧录和装电机。长按开机 → **通电一瞬间，指示灯亮、同时「啪」一声、主控冒了一点烟，随后快速升温。**
> 上电时引脚具体位置记不清，但**确定是完全照接线图一根根接的**。
> 主控的所有引脚都用**杜邦线**连接，**板子没有被焊过**，焊盘无异常。

这条补充很有价值，直接排除掉两类原因。

### 已可硬排除的

| 排除项 | 依据 |
| --- | --- |
| 固件 / 引脚配置 / PWM 设置 | 固件**从未烧进去**，芯片一直是空片，IO 全是出厂弱上拉输入态，不可能自己驱动负载 |
| 焊接热损伤、助焊剂漏电、焊盘短路 | 主控**没被焊过**，全部用杜邦线连接 |
| TX/RX 接反 | 发送对发送，电流极小，不足以烧芯片 |
| "随手乱接"式的接线错误 | 用户是**照图一根根接**的，不是凭感觉 |

**"啪 + 冒烟 + 瞬间升温"= 高能量事件**（反接 / 过压 / 短路），不是缓慢劣化。
**"指示灯亮"说明 7.4V 母线正常、开关机模块工作正常** → 故障点在 5V 侧或「5V → MCU」这一段。

### 最可能的死因（按可能性排序）

**① 送进 MCU 的 5V 极性反了 —— 而且很可能是"照图接反向"**

这是最符合全部证据的一条，也是最需要警惕的一条：
**用户完全照图接，但如果图上写的"第几脚"与实物左右方向相反，照图接的结果就正好是反接。**

接线图把 5V 接在 `T_VCC1`（上排第 **2** 脚）、GND 接在 `T_GND1`（上排第 **1** 脚）。
而 `元件清单.md` §7.1 描述上排是：

```text
上排：GND  VCC  GND  P55  VCC  P54  P17  P16  P11  P10
下排：GND  VCC  P30  P31  P32  P33  P34  P35  P36  P37
右侧：VCC  TX   RX   GND
```

**问题不在图的数据，而在"图 → 实物"的方向。**

《实际原件清单》明确写了 **"从正面看"**（正面 = 能看到芯片与丝印的那一面），本表与之一致。
但**排针焊在背面、杜邦线只能从背面插** —— 读字时看正面、插线时看背面，两次看到的是**镜像的两排**。
照着正面记住的"从左往右"去背面插，或整体数错一位，就会落到 `P10/P11` 那一端，或者正好把 5V 与 GND 对调。

这块板上排前三个脚是 `GND, VCC, GND` —— **在这三个脚之间错一位，必然反接**。

这与实测「空载发烫、断电阻不导通、上电只有 4.5V」完全一致（反接损伤的典型形态是**漏电而非硬短路**）。

**② MP1584 输出过高 —— 已排除（2026-10-21 实测）**

用户实测 `OUT+` ↔ `OUT−` = **5V**，且正负极**正确** → 电源模块排除。

**③ 买到的核心板本身是坏件 / 翻新件**（概率最低，但要买 2 块备用以排除）

### 结论（2026-10-21 二次修正：根因仍未定）

已排除：固件、焊接损伤、MP1584 过压、图纸引脚错误、**5V/GND 接反**
（用户目视确认上排确为 `GND, VCC, GND`，且当时接线正确）。

→ **根因重新标为「未定」。首要嫌疑：7.4V 窜进了 MCU 的 VCC。**

为什么锁定这条：量的是 **MP1584 模块的输出口**，不等于**送到板子的那根线**。
MP1584 有 `IN+/IN−`（7.4V）与 `OUT+/OUT−`（5V）两侧，开关机模块 `OUT+` 也是 7.4V ——
红线上错位一条，MCU 就吃到 8.4V。这个解释还和「只有 MCU 坏、TB6612 与编码器没事」完全吻合（它们的 5V 是对的）。

**定案动作（免费、立刻可做）**：拆掉 MCU，其余接线原样不动，上电，
量原来插进 MCU 的 `VCC` / `GND` 那两根线之间的电压 —— 读到 **7.4~8.4V** 即确诊。

完整排障流程与**保护方案**见 [排障文档.md](排障文档.md) §7。

## 上电前必做：四步验证（这次的核心）

> 上次缺的就是这几步。不用懂电路，会看万用表读数就行。

### 第 0 步：认字，不认位置

每根针旁边都印着丝印（`GND` / `VCC` / `P54` …）。**直接把线插到印着 VCC 的那根、印着 GND 的那根。**

> **永远不要用「从左数第几个」来定位引脚。** 板子的两面看过去顺序是镜像的，数位次一定会错。
> 接线图里的"上排第 1 脚"只作为辅助，**实际动手只认丝印字**。

### 第 1 步：量降压输出（此时 MCU 不接）

- 万用表直流 20V 档，红笔 `OUT+`、黑笔 `OUT−`
- 必须是 **4.95 ~ 5.10V**；**超过 5.2V 就不要接任何东西**，先调或直接换模块

### 第 2 步：量「准备送进 MCU 的那两根线」的极性 ← 这一步能救命

不要先插板子，**先量线**：

- 黑笔夹在**你打算接 MCU GND 的那根线**上
- 红笔点在**你打算接 MCU VCC 的那根线**上
- 读数必须是 **+5V**
- **如果读到 −5V，说明两根接反了** —— 立刻换过来

这一步 10 秒就能做完，能挡住上面最可能的死因。

### 第 3 步：先串电阻限流

- 在 5V 进 MCU 前串 **100Ω / 1W** 电阻再上电
- 板端电压被拉到接近 0V → 有短路，**立刻断电**，别直连
- 电压正常、电阻不烫 → 板子没问题，断电去掉电阻，正式接

### 第 4 步：先给 MCU 单独上电，摸温度

正常空片只是**微温**。发烫立即断电。
确认 MCU 正常后，再逐个接回 TB6612、编码器、电位器，**每接一个复测一次电压 + 摸一次温度**。

> 杜邦线接电源是隐患（易松、易错位、接触电阻大）。电源这两根建议换**带锁扣的端子**或至少单根插紧，
> 并用**红色标 5V、黑色标 GND**，两头都贴上标签。

## 重启清单（照做，别跳步）

### 先买东西（约 ¥30）

| 东西 | 数量 | 关键词 | 备注 |
| --- | --- | --- | --- |
| STC8G1K08 **SOP16 核心板** | **2 块** | `STC8G1K08 最小系统板 开发板` | 别买带 `A` 后缀的（引脚定义不同） |
| SS14 / 1N5819 肖特基二极管 | 5 只 | `SS14 肖特基二极管 贴片/直插` | 做反接保护，见下 |
| 100Ω 1W 电阻 | 2 只 | `100欧 1W 电阻` | 第一次上电做"穷人限流" |

### 换板前：先证明电源是干净的

1. **不接任何板子**，上电空载，把 MP1584 输出调到 **5.00V**（4.95–5.10V）。
2. **带载复测**：接上 TB6612、编码器、电位器后再量一次，带载仍应 ≈5.0V。
3. 断电，量 `OUT+` ↔ `OUT−` **不应导通**。
4. **调好立刻固定电位器**（螺丝胶 / 指甲油 / 热熔胶）——这是上次最可能被忽略的一步。
5. 更省心的替代：**换固定 5V 输出的降压模块**，彻底去掉"可调电位器"这个变量。

### 换板前：先确认 TB6612 和编码器没被一起烧坏

死因若成立在「5V 过压」，它们和 MCU 吃同一路 5V，**不能默认是好的**。换新 MCU 之前先测：

| 件 | 怎么测（全部断电、不接 MCU） | 合格标准 |
| --- | --- | --- |
| TB6612 | 通断档量 `VCC` ↔ `GND` | **不导通**；若导通或阻值很低（<100Ω）→ 已损坏，换 |
| 编码器 | 通断档量 `蓝(5V)` ↔ `黑(GND)` | **不导通** |
| 电位器 | 量 1↔3 两端电阻 | 约 **10kΩ** 且顺滑变化 |

> 只要有一件测出导通，说明 5V 确实出过问题 —— 那就更要按"过压"这条来防。

### 防反接（这次最重要的一条）

在 5V 进入 MCU 之前串一只 **SS14 肖特基**（压降约 0.3–0.4V）：

```text
MP1584 OUT+ ──▶|── MCU VCC
              SS14
```

- 接反了只是不工作，不会烧板；
- 看完压降后把 MP1584 调到 **5.3V 左右**，让板端仍落在 5.0V（STC8G 工作范围 1.9–5.5V，很安全）。

同时：**5V 用红线 + 热缩管标字，GND 用黑线；插头做防呆**（剪掉一个针位或灌胶固定）。

### 第一次上电：先串电阻

新板到手后，先**串 100Ω/1W 电阻**再上电：

- 若板端电压被拉到接近 0V → 有短路，立刻断电，别直连；
- 若电压正常、电阻不烫 → 板子没问题，断电，去掉电阻，再正式接。

上电后**摸温度**：正常空片只是微温；发烫立即断电。

### 烧录时（和上次一样，别按位置对齐）

| CH340 | 接板子 |
| --- | --- |
| `TXD` | 右侧 **`RX`**（＝P3.0） |
| `RXD` | 右侧 **`TX`**（＝P3.1） |
| `GND` | `GND` |
| `VCC` | **不接** |

STC-ISP：型号 `STC8G1K08-20/16PIN`、IRC **24MHz**、**不要**勾「P5.4 用作复位脚」、
点下载 → 出现"正在检测单片机" → **长按电源键开机**。

> 烧录优先在**裸板阶段**做：只接主控，不接电机和 TB6612。

### 烧录成功后

断电，拔掉三根烧录线 → **每接回一个模块，复测一次 5V + 摸一次温度** → 异常立即回退定位。

## 未来改成 ESP32（可行，而且更省事）

这个项目 **不必为了"必须用 ESP32"而重做**，但改成 ESP32 有三处**会直接升级体验**，也有三处**必须改，否则烧板**。

### 必须改的三处（否则会损坏 ESP32）

1. **电位器上端从 5V 改接 3.3V**
   ESP32 的 ADC 只能承受 0–3.3V。现在滑条上端接 5V → 灌进 ADC 会损坏芯片。
2. **编码器供电改 3.3V，或对 A/B 相加分压**
   若编码器仍用 5V 供电，A/B 输出是 5V 方波 → 直连 ESP32 超压。
   多数霍尔编码器 3.3–5V 都能工作，**优先改 3.3V 供电**。
3. **电平匹配**
   TB6612 的 `VCC`（逻辑电源）范围 2.7–5.5V，接 3.3V 即可让 ESP32 的 PWM/方向直接驱动，**不用电平转换**。
   `VM` 仍是 7.4V 母线，不变。

### 升级点

- **PWM**：用 LEDC 硬件 20kHz，不再靠软件定时器占 CPU；
- **编码器**：ESP32 有 PCNT 硬件正交解码，高转速不丢脉冲（STC8G 那套 INT0/INT1 软件计数在高速下会丢）；
- **烧录**：ESP32 板载 CH340，插 USB 就能烧，不用再外接 USB-TTL、不用冷启动断电；
- **扩展**：Wi-Fi 远程控制、参数在线调、堵转/温度保护、OLED 显示状态。

### 迁移路径（不建议一次全改）

1. 先用**新的 STC8G 板**把现有固件跑通 —— 验证机械结构与闭环参数（这一步不改任何逻辑）；
2. 再换 ESP32，把 PWM / 编码器 / ADC 三处按上面改掉；
3. 最后加 Wi-Fi / 屏 / 保护逻辑。

> 先让"旧方案能跑"，再换平台。否则机械问题、电气问题、移植问题会混在一起，无法定位。

## 不要再踩的坑

1. ❌ 不要把"VCC↔GND 不导通"当成芯片没坏的证据（漏电型损坏测不出来）。
2. ❌ 不要按位置一一对应插烧录线 / 电源线 —— 这块板 `TX`=P3.1、`RX`=P3.0，电源脚还是 GND 在前。
3. ❌ 不要靠丝印位置猜 GND，用通断档以电池负极为基准找。
4. ❌ 不要在空载发烫的板子上反复上电。
5. ❌ 不要"调到 5.00V 就一劳永逸"——任何焊接、插拔、装壳之后都要复测。
