# 电气玩具（electric-toy）

> **交接说明 · 最后更新：2026-10-20**
> 这份文档是给「下一位接手的人或大模型」看的**唯一入口**：读完它 + 下面的《文件地图》，就能直接接着干，
> 不需要从零重新理解这个项目。所有尺寸单位 **mm**。

---

## 0. 一句话

一个**卷轴式打磨装置**（桌面小工具 / 电气玩具）：盒子内部装电路板、电机、电池；
电机经「主齿轮 + 2 从齿轮」驱动**两根伸出盒体 50mm 的卷轴筒**（传动砂布，往复 ±5cm）；
盒外正前方一根**竖直的待打磨柱体 Ø30×150**，被一个**双爪夹具**夹住，柱体位于两根卷轴筒之间、垂直于两转轴。

## 2. 硬件现状（**已确认，不要再改**）

- **主控** STC8G1K08 SOP16 最小系统板（排针向上焊）。SDCC 编译，主频 24MHz。**⚠️ 2026-10 该板已损坏（空载发烫），待更换。**
- **驱动** TB6612FNG（只用 A 通道：PWMA/AIN1/AIN2；`BIN1/BIN2` 接地；`STBY` 接 5V）。
- **电机** JGB37-520，DC 6V，减速比 1:56，带 AB 相霍尔编码器（11PPR 方波），自带 PH2.0 母座。
- **电源** 2S 103450 锂电（7.4V）→ 2S 保护板（带均衡）→ 一键开关机模块（长按 3s）→ 7.4V 母线。
- **降压** MP1584EN → 5V（供 MCU / TB6612 VCC / 编码器 / 电位器）。**上电前必须先调到 5.00V**。
- **充电** CN3761 2S 充电板，Type-C 输入，从盒体**左侧面**露出。
- **调速** 直滑电位器 B10K 45mm；**模式键** 轻触按键 6×6×5。
- **烧录** CH340 USB-TTL（**`TXD`→板右侧 `RX`＝P3.0**、**`RXD`→板右侧 `TX`＝P3.1**、`GND` 共地、**`VCC` 不接**，需断电再上电冷启动）。
  > 实测：板右侧 4 针丝印 **`TX`＝P3.1、`RX`＝P3.0**，写的是"芯片自己的收发脚"，**接外部模块必须交叉**，不能按位置一一对齐。

**引脚映射**：`P5.4=PWMA`、`P5.5=AIN1`、`P3.7=AIN2`、`P3.2=编码器A(INT0)`、`P3.3=编码器B(INT1)`、`P1.0=滑条 ADC`、`P1.1=模式键`。

**供电地线关键一条**：开关机模块 `OUT−` 用 **22AWG 硅胶线直连 TB6612 的 GND**，让电机大电流直接回电池、
不穿过 MP1584（否则地弹 / 5V 瞬降 / MCU 复位）。

**三个工作模式**（共用同一套闭环，区别只在「到位后下一个目标怎么产生」）：
`待机 → 模式1（±5cm 两点往复，单程 10cm）→ 模式2（±2cm）→ 模式3（±4.7cm 随机折返）→ 待机`
闭环 10ms；死区 0.3cm=49 脉冲；软区 1.5cm=249 脉冲线性减速；硬限位 ±830 脉冲；
占空比 0~80%；软启动 1%/ms；`PULSES_PER_CM=166`；堵转 5s 保护。
> 权威细节看 `三个工作模式.md`（含参数总表与脉冲当量推导），**不要凭记忆改参数**。

## 3. 外壳设计

### 3.1 内部布局（v0.1 · **已冻结，不再改动**）

- 盒体外廓 **104（Y 宽）× 86（X 深）× 74（Z 高）**；坐标系 Z 朝上，X 从 0（控制面）到 86（转轴面板）。
- 齿轮平面 **X = 10~18**（厚 8）：主齿轮 z26 在 **Y=0**，两个从齿轮 z22 在 **Y=±30**（m1.25）。
- 电机 Ø37×约 59，**轴向 ∥ X**，占 **X = 18~78**、居中 **Y=0**、轴心 **Z=37**。
- 两根转轴 **Y=±30**、轴颈 Ø6，沿 X 贯穿 X=86 面板，**轴承 Ø6×13×4 固定在壳内**。

### 3.2 外部细节（**已确认**）

| 部位 | 内容 |
|---|---|
| 控制面（X=0，与转轴面相对） | 2 颗轻触按键 + 1 个滑动电位器（行程 45）|
| 转轴面板（X=86） | 两根 **Ø20 卷轴筒**，伸出 **50**，**轴距 60**、**净空 40** |
| 柱体 | **Ø30×150，竖直**立于两卷轴筒之间（**Y=0**），**⊥ 两转轴、⊥ 夹具** |
| 双爪夹具 | 两根**直棒 ∥ 转轴（X 向）**，**左右各一（Y=∓19）**，水平高度 **Z=62**；<br>· 内端 → 之间夹一根**压簧**；<br>· 中部 → **竖直小销（⊥棒体、∥Z）插进面板的竖直槽**，作为**支点**；<br>· 外端 → **半圆爪（凹侧朝内）横抱柱体** |
| Type-C | 焊在充电板上，从**左侧面**露出 |

### 3.3 夹具开合：**方案 C（已定，无操作件）**

两个半圆爪 = 弹簧压紧的杠杆，闭合内径比柱体外径**小 0.3~0.5mm**（爪内贴 **1mm 硅胶板**作内衬），**PETG 打印**。
→ 柱体从侧面推入时把两个爪顶开，到位后弹簧弹回夹住；取出时反向拉出同理。
**不需要任何推杆 / 按钮 / 联动件。**（备选：两根侧面推杆；单键收口叉 —— 仅在实测推入太费力或要单手操作时才考虑。）

### 3.4 待定 / 待办（**接手就从这里开始**）

1. **内部布局避让（最要紧）**：夹具的"动力端"（两根直棒的内端 + 压簧）在盒内占掉一块空间 ——
   约 **X 74~86、Y ±25、Z 54~70**。原来的 **7×9cm 洞洞板若平铺在电机正上方（Z≈57）会正好撞上**
   → 需要：板挪位 / 拆成两块小板 / 或给这块留缺口。
2. **上盖 / 下盖分割线** 未定 → 定了才能出**打印件清单**（外壳上下盖、卷轴筒×2、齿轮×3、爪×2、支点销×2、按键帽、滑块帽、Type-C 挡板）。
3. **砂布走带方式**未定（卷轴筒怎么带砂布、±5cm 行程如何落到柱体上）；3D 页里**没有表示打磨机构**。
4. **正式 spec / 实现计划**未写（brainstorming 流程还差：写设计文档 → 自审 → 用户评审 → 出实现计划）。
5. **实测项**：半圆爪内径配合量（0.3~0.5mm）、压簧刚度（按砂布往复的拖动力试，不是"能夹住不掉"就行）。

### 3.5 已作废的设计（**别再拿出来**）

- ❌ 干湿分离 / 接水盘 / 油封（TC 8×16×5）—— 用户明确不要。
- ❌ 因此"卷轴轴颈要不要做 φ8 阶梯轴适配油封"这个问题也一并作废。
- ❌ 早期《工作逻辑》里"必须跨越零位""相邻两次方向必须相反"——当前固件并未实现。

## 5. 怎么打开可视化页面（**最容易踩的坑**）

- **普通 HTML**（`2D接线图.html`、`.brainstorm/content/*.html`）→ 直接双击即可。
- **任何含 `import ... from 'three'` 的页面**（所有 3D 页面）→ **必须走本地 HTTP**，`file://` 会触发 CORS 拦截 → **白屏**。
  在本目录执行：
  ```bash
  python -m http.server 8792 --bind 127.0.0.1 --directory .
  ```
  然后浏览器打开 `http://127.0.0.1:8792/3D%E9%A2%84%E8%A7%88-v0.1.html`
  （文件名是中文，URL 会被百分号编码；也可用 `python -m http.server` 后在文件列表里点）。
  或者用 VS Code 的 **Live Server** 插件。用完记得关掉服务。

## 6. 软件工具链

- **编译器**：SDCC 4.5.0（本机在 `C:\MY\Program Files\SDCC`）。在本目录跑 `05-软件代码/build.bat` → 产出 `main_sdcc.hex`。
  （不要用 Keil：评估版有 2KB 代码限制。）
- **烧录**：STC-ISP **v6.96Z**。选 **STC8G1K08** → 主频 **24MHz** → **不要勾「P5.4/RST 用作复位脚」**（勾了 PWM 无输出、电机不转）
  → 点「下载」→ 提示"正在检测单片机"时给板子**断电再上电**（CH340 无自动冷启动）。
- **接线**：`TXD`→板右侧 `RX`（P3.0）、`RXD`→板右侧 `TX`（P3.1）、`GND`→`GND`、`VCC` 不接。
  实测右侧丝印 `TX`＝P3.1、`RX`＝P3.0，**必须交叉**；模块跳线选 **5V**。
- **烧录最佳时机**：**只接主控板、未接电机与驱动的装配阶段**，避免装壳后反复拆装。
- **上电自检**：上电后主控芯片应只是**微温**。若迅速发烫（尤其空载），说明芯片已损坏，**立即断电**，不要反复上电。

## 7. 工作约定 / 用户偏好（**新电脑上的大模型请先读这段**）

- 所有产出文件都放进本项目目录（`电气玩具/`）——这是硬性要求。
- 用户**不喜欢焊接**：固定优先 M3 铜柱+螺丝、模块间用杜邦线；结构件外壳全部自行 3D 打印（不用提供外壳设计）。
- 采购条目要给**引脚数 / 淘宝关键词 / 避坑点**。
- 用户偏好**可视化的 HTML 页面**来理解技术内容（纯文字对话框他觉得不直观）；选型类问题优先做成可点选的交互页面，别让他手打选项。
- 版本控制：仓库 `electric-toy`，分支 `main`。
- 3D 预览页命名规范：`3D预览-vX.Y.html`，依赖本地 `lib/`。
- 已知硬件踩坑（勿重复）：MP1584 不调 5V 会烧 MCU；STC-ISP 勾 P5.4 复位脚 → PWM 无输出；
  齿轮 D 孔要 6.2×5.7 否则装不进电机轴；杜邦线过流不够（电源线用 22AWG）；USB-TTL 认准 CH340 避开 PL2303；
  2S 充电板必须接保护板 **`P+`/`P−`**，不能接 `B+`/`B−`（接 B 侧会绕过保护 FET → 充电无保护，且保护板锁死、开关机后输出归零、每次都要短接 `P−`↔`B−` 才能唤醒）；
  **板右侧丝印 `TX`＝P3.1、`RX`＝P3.0**，CH340 必须交叉接（`TXD`→`RX`、`RXD`→`TX`），按位置对齐会接错；
  **MP1584 校准 5.00V 之后，任何焊接 / 插拔动作都要复测**（电位器很小，极易被碰偏；2026-10 疑似因此烧毁一块主控板）；
  **主控板空载就发烫 = 芯片已损坏**，不要反复上电，直接换板（STC8G1K08 SOP16 核心板，约十几元）。
