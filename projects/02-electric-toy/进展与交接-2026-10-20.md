## 2. 烧录失败的时间线

1. 用 `stcgal`（COM3）烧录，多次冷启动，日志始终停在 `Waiting for MCU, please cycle power:`，**芯片零字节响应**。
2. 改用官方 **STC-ISP v6.96Z**，逐项核对设置（全部正确，见 §3），仍提示「连接似乎不畅」，反复发握手脉冲无响应。
3. 实测共地：**电池负极 ↔ MCU GND 通**、**电池负极 ↔ CH340 GND 通** → **共地正常**（早期一次"通到 5V、不通到地"的读数是探错端子造成的假象）。
4. 实测板子丝印：**右侧 `TX` ↔ P31、`RX` ↔ P30** → 板子丝印写的是"芯片自己的收发脚"，**正确接法必须交叉**。
5. **一一对应**与**交叉**两种接法都试过，均无法检测到芯片。
6. 经排查确认：问题不在接线方向、不在软件设置、不在共地。线材、TTL 电平、芯片型号几条原因均已排除。
7. **判决性测试**：拔掉全部外部负载（TB6612、编码器、电位器、电机、三根烧录线），**只留 `VCC`/`GND`** → 芯片仍**迅速升温、很烫**。
8. 断电量 `VCC`↔`GND`：**不导通**。但漏电型损坏不必是硬短路（见 §4 说明）。

## 4. 判定：主控板已损坏

**判据（唯一且充分）**：空片状态、无任何外部负载、仅接 `VCC`/`GND`，芯片**迅速升温、很烫**。

- 一颗正常的 STC8G1K08 空片工作电流只有几 mA，**几乎不升温**。
- 空片引脚全部是弱上拉输入，**不可能自己驱动负载**，所以发热只能来自**芯片内部漏电/短路**。
- `VCC`↔`GND` 断电阻**不导通**并不矛盾：CMOS 损伤常见形态是**漏电型**（几百 Ω～几 kΩ，或只在 5V 下导通），通断档的蜂鸣阈值约 30～50Ω，测不出来。
- 该损坏**不可逆**，不要尝试修复。

### 可能死因（按可能性排序，尚不能 100% 区分）

1. **焊 TB6612 / 编码器时碰偏了 MP1584 的微调电位器** → 输出一度高于 5.5V 甚至接近 7.4V。
   关键漏洞：**5V 校准是在焊接之前做的，焊完从未复测带载电压**。
2. 更早那次「冒烟」事件留下的供电隐患（保护板 MOS 受损 / 上电尖峰）。
   > 待补充：当时**哪个模块冒烟**、**主控板是否在电路中通电**——这能帮助确认死因。
3. 反复试烧录期间，GND 曾短暂错接到 VCC（5V 反灌进钳位二极管，累计损伤）。
4. 淘宝核心板本身为坏件 / 翻新件。

> 说明：**TX/RX 方向接反本身不会烧芯片**（发送端对发送端，电流极小）。

## 5. 换新板后的操作顺序（照做，别跳步）

1. **买板**：STC8G1K08 **SOP16 核心板**（约十几元），建议一次买 2 块备用。
2. **先验电源，不接新板**：
   - 断电，通断档量 MP1584 `OUT+`↔`OUT−`：**不应导通**；
   - 上电**空载**，把输出调到 **5.00V**。
   - 若调不到 5.00V，或 `OUT±` 已导通 → **先换降压模块**，否则新板会被烧。
3. **裸板验板**：新板**什么都不接**，只接 `VCC`/`GND` 上电：
   - 板 `VCC` 对 `GND` 应为 **4.95～5.10V**；
   - 芯片应只是**微温**。若发烫 → 立刻断电（板有问题 / 电源有问题）。
4. **烧录（先不接电机）**：
   | CH340 | 接到板子 |
   |---|---|
   | `TXD` | 右侧 **`RX`**（＝P3.0；或下排第 3 脚 P30） |
   | `RXD` | 右侧 **`TX`**（＝P3.1；或下排第 4 脚 P31） |
   | `GND` | `GND` |
   | `VCC` / `5V` | **不接** |

   STC-ISP 设置：型号 `STC8G1K08`（SOP16 项 `STC8G1K08-20/16PIN`）、串口选 CH340 的 COM 口、
   载入 `main_sdcc.hex`、IRC **24MHz**、勾选「复位脚用作 I/O 口」、**不勾**「P3.2/P3.3 冷启动条件」。
   点「下载/编程」→ 出现「正在检测单片机…」→ **长按电源键开机**。
5. **烧录成功后**：断电，拔掉三根烧录线；再逐个接回外部模块，**每接一个都复测 5V + 摸温度**，异常立即回退定位。
6. **防再烧**：MP1584 电位器调定后点螺丝胶/指甲油固定，或改用**固定 5V 输出**的降压模块；焊接一律断电、烙铁接地。

## 9. 不要重复的弯路

1. ❌ **不要按"位置一一对应"插烧录线**：板右侧是 4 针（`VCC/TX/RX/GND`），模块只有 3 根信号，按位置对齐会整体错一格。
2. ❌ **不要靠丝印位置猜 `GND`**：用通断档以电池负极（`B−`）为基准找真实地。
3. ❌ **不要用 stcgal 反复试 STC8G**：兼容性不如官方 STC-ISP，浪费时间。
4. ❌ **芯片空载发烫时不要反复上电**：每开一次都在加重损伤，直接换板。
5. ❌ **MP1584 调好 5.00V 不等于一直是对的**：任何焊接、插拔、装壳之后都要复测。
6. ❌ **不要把"VCC↔GND 不导通"当作芯片没坏的证据**：漏电型损坏测不出来。
