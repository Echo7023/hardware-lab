## 一、问题 1 · MP1584 必须先调到 5.00V（最高风险，做错会烧主控 / 编码器）

**为什么**：MP1584 是**可调**降压模块，出厂输出是随机的。它的 `OUT+` 同时供给 STC8G 主控、TB6612 的 `VCC`/`STBY`、电机编码器（蓝线）、电位器。只要输出偏高（比如 6V 以上），这几样都会被烧。

**工具**：数字万用表（直流电压档）、绝缘小螺丝刀（匹配模块上的可调电位器）、几根临时测试线。

**步骤**：

1. **断开 MP1584 输出侧的一切负载**——主控、TB6612、编码器、电位器**全部不接**。只保留输入：`IN+ → 7.4V 母线`、`IN− → GND`。
2. 万用表打 **直流 20V 档**，红笔接 `OUT+`、黑笔接 `OUT−`（表笔拿稳，别滑到隔壁脚造成短路）。
3. 长按开关机键 3 秒，上电。
4. 读电压。若不在 5.00V：
   - 用**绝缘**小螺丝刀**缓慢**旋模块上的可调电阻，**每旋一点停一下看读数**（多圈电位器，正转升还是降，当场从读数就能看出来）。
   - 调到 **5.00V**（可接受 4.95 ~ 5.10V）。
   - **断开电**再做下一步，避免手滑短路。
5. 调好后用热熔胶或记号笔**锁住电位器**，防止装机后振动漂移。
6. 接上全部 5V 负载（主控 / TB6612 / 编码器 / 电位器）后，**再复测一次** `OUT±`，带载应仍在 5.0V 附近；若掉到 4.8V 以下，检查是否短路或负载过重。

> **红线：调到 5.00V 之前，绝不接主控、TB6612、编码器、电位器。**

## 二、问题 2 · STC-ISP 烧录时不要勾 P5.4 复位脚

**为什么**：固件用 P5.4 输出 20kHz 软件 PWM。STC8G1K08 的 P5.4 出厂可被配置成 `/RST` 复位脚；一旦勾选，P5.4 就不再是普通 IO，**PWM 无输出 → 电机不转、滑条调速失效**。

**步骤**：

1. 打开 **STC-ISP**，芯片型号选 **STC8G1K08**。
2. 载入 `05-软件代码/main_sdcc.hex`。
3. 主频设 **24MHz**。
4. 在"硬件选项"里找到与 **P5.4 / RST / 复位脚** 相关的勾选项，**保持默认（不要勾）**。不同版本措辞可能是"P5.4 用作复位脚""将 P5.4/RST 设置为复位脚"等，认准带 **P5.4** 字样的那一个。
5. 点"下载/编程"，提示"正在检测单片机"时给板子**断电再上电**（CH340 无自动冷启动）。

**验证**：烧好后进 ±5cm 模式，把滑条从最左推到最右，电机转速应明显变化。**若电机完全不转、滑条无反应，第一嫌疑就是这条被勾上了**——重新烧录并取消勾选。

## 三、问题 3 · 确认最小系统板上 P5.4 / P5.5 / P3.7 是纯引出脚

**为什么**：少数 STC8G 最小系统板会把 P5.4 接上复位按键/RC，或给某些脚加了固定上拉/下拉。这三个脚一旦被板载电路占用，**PWM 或方向位会失灵**。

**工具**：数字万用表（通断 / 二极管蜂鸣档）。**全程不通电。**

**步骤**：

1. 认准板上丝印 **P54 / P55 / P37** 三个针脚（板级丝印排布见 `元件清单.md` 第七节 7.1）。
2. 万用表打**蜂鸣（通断）档**。红笔固定在这三个针脚之一上，黑笔依次点：
   - 板上的**复位按键**两个引脚；
   - 板上标 **RST / RESET** 的焊盘或元件脚；
   - 板上**其它非 P54/P55/P37 的引脚**。
3. 判断：
   - 若**蜂鸣（导通）** → 该脚被板载电路占用，**不能直接当 IO 用**：拆掉占用它的元件（复位 RC / 按键），或换一块"P5.4 / P5.5 纯引出"的板子。
   - 三个脚都**只连通对应排针、不连复位电路**，才算合格。
4. 再量这三个脚对 **VCC / GND** 的通断：正常应是**不通（高阻）**；若一直导通，说明有固定上下拉，也要处理。

**上电后验证**：

- 滑条推拉 → 电机转速变化 → 说明 P5.4 PWM 正常；
- 电机能正反转 → 说明 P5.5 / P3.7 方向位正常。

## 五、上电顺序（照这个顺序来，别一次全插）

1. **电池组 + 保护板 + 开关机**：量 7.4V 母线是否正常，试长按开机 / 关机。
2. **MP1584 空载调到 5.00V**（见问题 1）。
3. **只插主控**：用 CH340 烧录（`TXD→板右侧 RX`＝P3.0、`RXD→板右侧 TX`＝P3.1、`GND↔GND`、**VCC 不接**，下载时断电再上电），试滑条 / 按键反应。
4. **接 TB6612 与编码器**（先不接电机动力线）：看电机方向。
5. **最后接电机红 / 白动力线**：进 ±5cm 模式，用尺量实际行程校准 `PULSES_PER_CM`。

## 六、烧录前检查清单（逐项勾选，全打勾才开烧）

> 对应「上电顺序」的第 3 步。此时应处于**裸板**状态（TB6612 / 电机动力线都还没接）。

### A. 硬件与接线

- [ ] USB-TTL 是 **CH340 芯片**（不是 PL2303），已插入电脑 USB 口
- [ ] 模块 **`TXD` → 板右侧 `RX`（＝P3.0）**、**`RXD` → 板右侧 `TX`（＝P3.1）**（**交叉**接，别接反；实测右侧 `TX`↔`P31`、`RX`↔`P30`）
- [ ] 模块 **`GND` → 板 `GND`**（必须共地）
- [ ] 模块 **`VCC` 不接**
- [ ] 主控板已用 **5V** 供电（**不是 7.4V**），且与模块共地
- [ ] 上电后主控芯片只是**微温**；若迅速发烫 → 芯片已损坏，**立即断电换板**（2026-10 已发生一次）
- [ ] 板子**尚未接** TB6612 / 编码器 / 电机动力线（保持裸板烧录）
- [ ] 杜邦线插实不松动；`P3.0` / `P3.1` 没有其它东西占用

### B. 电脑与驱动

- [ ] 设备管理器 →「端口(COM 和 LPT)」里出现一个新的 **COM 口**（记下是 COM几）
- [ ] 看不到 COM 口 → 换 USB 线 / 换口重插，或确认模块确实是 CH340

### C. 软件设置（STC-ISP）

- [ ] 单片机型号选 **STC8G1K08**（**不是** STC8G1K08A）
- [ ] 程序文件已载入 **`main_sdcc.hex`**
- [ ] 运行主频（IRC 频率）设 **24MHz**
- [ ] **未勾选**「P5.4 / RST 用作复位脚」
- [ ] COM 口选的是 B 步里那个口
- [ ] 其余选项保持默认

### D. 文件

- [ ] `05-软件代码/main_sdcc.hex` 是最新编译产物（改过代码就先跑一遍 `build.bat`）

### E. 操作要点（开烧时）

- [ ] 先点「下载/编程」→ 看到 **"正在检测单片机…"** → 再给板子**断电、等 1 秒、重新上电**
- [ ] 烧录完成后**断电**，把 `TXD` / `RXD` / `GND` 这三根从板子上**拔掉**（它们只是烧录用）

> 以上全部打勾 → 可以开始烧录。任意一项不通过，先解决再继续。
