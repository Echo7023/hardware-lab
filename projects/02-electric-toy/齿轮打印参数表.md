# 齿轮打印参数表（主 26 齿 D 孔 / 从 22 齿圆孔，m1.25）

> **用途**：直接用 3D 打印齿轮，不再采购。把「一、生成器输入参数」填进拓竹参数化齿轮生成器，用「二、核对尺寸」验证生成结果对不对。
> **配套机构**：卷轴筒 Ø20、两卷轴轴间距 60mm、净空 40mm、工件 Ø30×150mm、电机 JGB37-520（6V 90rpm，Ø6 D 型轴，对边 5.5）、轴承 6×13×4（内径 6 / 外径 13 / 厚 4）。
> **为什么是 m1.25 而不是 m0.8**：0.4 喷嘴下 m0.8 的齿顶最薄处只有 0.60mm（不足 1.5 条走丝），会打糊、偏紧；m1.25 齿顶 0.89mm，过了「2× 线宽」这条稳线，一次成功率高得多。

---

## 一、生成器输入参数

| 参数 | 主齿轮（装电机轴） | 卷轴齿轮 ×2（装卷轴） |
|---|---|---|
| 模数 m | **1.25** | **1.25** |
| 齿数 z | **26** | **22** |
| 压力角 α | 20° | 20° |
| 齿宽（厚度）b | **8mm** | **8mm** |
| 孔径 | **D 形孔 Ø6.2，对边 5.7** | **圆孔 Ø6.2** |
| 变位系数 x | 0（标准） | 0（标准） |
| 齿顶高系数 ha\* | 1.0 | 1.0 |
| 齿根高系数 hf\* | 1.25 | 1.25 |
| 齿隙 / 背隙 | **0.15mm** | **0.15mm** |
| 螺旋角 | 0°（直齿） | 0°（直齿） |

> 主齿轮用 **D 形孔 Ø6.2（对边 5.7）**，套电机 D 型轴（轴 Ø6、对边 5.5，孔径放大 0.2mm 才好装入）；两个卷轴齿轮改用 **圆孔 Ø6.2**，套 Ø6 卷轴轴颈，靠顶丝（或胶）防打滑。26、22 都是偶数，两个卷轴齿轮相位完全相同，直接对齐即可。

## 二、核对尺寸（和下面不符就是参数填错了）

| 项目 | 主齿轮 z26 | 卷轴齿轮 z22 |
|---|---|---|
| 分度圆直径 d = m·z | **Ø32.5** | **Ø27.5** |
| 齿顶圆直径 da = m(z+2) | **Ø35.0** | **Ø30.0** |
| 齿根圆直径 df = m(z−2.5) | **Ø29.375** | **Ø24.375** |
| 孔径 | D 形 Ø6.2 / 对边 5.7 | 圆孔 Ø6.2 |

**齿轮副校验**

- 中心距 a = m(z₁+z₂)/2 = 1.25×(26+22)/2 = **30.0mm**
- 两卷轴轴间距 = 2a = **60.0mm** ← 盒体上两个卷轴轴心就按这个距离做
- 净空 = 60 − 卷轴筒 Ø20 = **40.0mm** ✓（正好是要求的下限，桶径别再加大）
- 齿轮传动区总宽 = 2×(30 + 30.0/2) = **90.0mm** → 盒内宽 ≥ **92mm**
- 孔壁厚：主齿轮齿根到孔边 ≥11.7mm、从齿轮 ≥9.2mm，D 孔安全，不会撑裂轮毂

## 三、装配（主齿轮走 D 孔，卷轴齿轮走圆孔）

- 主齿轮 D 孔的平边对准电机轴的 D 面，直接套入、推到轴根。
- 两个卷轴齿轮用圆孔套 **Ø6 卷轴轴颈**，用 M3 顶丝（或胶）锁死防打滑；卷轴轴颈整段 Ø6 即可（轴承 6×13×4 内径同为 6，不必变径）。
- 装完**手动转一圈确认无卡滞**。
- ⚠ 齿轮平面必须整片位于工件的前方（轴向上错开）。从动轮齿顶圆半径 15.0mm，工件半径 15mm，正好相等——**齿轮和工件绝不能共面**，靠盒壁 + 轴承段（厚 4mm）错开即可。

## 五、打印建议（PETG，0.4 喷嘴）

- 喷嘴 0.4mm；**层高 0.12~0.16mm**；外墙 3 圈、线宽用默认（Arachne 会自动调整，不建议手工改小线宽）；填充 ≥40%
- 摆放：齿轮**平放**（齿形在 XY 平面、齿宽沿 Z），薄齿不要加支撑
- 齿隙已按 0.15mm 设好；若装上去仍偏紧（PETG 收缩会略偏大），用砂纸轻磨齿面，或把齿隙加到 0.2mm 重生成
- **孔打印方向**：平放打印时主齿轮 D 孔的平边让它朝下（平边是短桥接，Ø6 小孔没问题），避免平边朝上悬空；卷轴齿轮是圆孔，无此问题
- 材料：PETG 韧性好、耐打磨粉尘，齿根应力只有个位数 MPa，强度余量 5 倍以上，完全够
