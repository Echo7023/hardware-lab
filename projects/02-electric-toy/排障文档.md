# 排障文档 · 首次上电烧毁主控

> 针对 2026-10 电动玩具首次上电烧毁 STC8G1K08 的事件。
> 配套：[引脚对应表.md](引脚对应表.md)、[上电前检查与接线修正.md](上电前检查与接线修正.md)。

## 0. 一句话结论

**根因仍未定 —— 但已经排出五个方向，而且不花钱就能再做一次定案。**

已排除：

- **MP1584 输出过高 / 输出反接** → 用户实测 `OUT+`↔`OUT−` = 5V、极性正确
- **图纸引脚错误** → 三张图与《实际原件清单》逐项一致（见 [引脚对应表.md](引脚对应表.md) §三）
- **5V/GND 接反** → 用户目视确认上排确为 `GND, VCC, GND`，且接线正确
- **固件 / 焊接** → 固件从未烧入（空片），主控也从未焊接

**首要嫌疑：7.4V 窜进了 MCU 的 VCC。**
理由：量的是**模块输出口**，不等于**送到板子的那根线**；MP1584 的 `IN±`(7.4V) 与 `OUT±`(5V) 在同一块板上，
开关机模块 `OUT+` 也是 7.4V。这一路接错，只会烧 MCU，TB6612 与编码器（接在真正的 5V 上）不受影响 —— 与现象完全吻合。

**定案方法见 §7.1，保护方案见 §7.2。**

## 2. 为什么"图是对的、也是照图接的"，仍然会反接

这是本次最需要讲清楚的一点。

### 2.1 插线必须在背面，丝印却在正面

核心板的排针焊在**背面**，杜邦线也只能从**背面**插进去。
但丝印（GND / VCC / P54…）印在**正面**。

也就是说：**你"读字"时看的是正面，"插线"时看的是背面 —— 两次看到的是镜像的两排。**

正面：

```text
正面看：  GND   VCC   GND   P55   VCC   P54 ...
          ← 左                                右 →
```

翻到背面插线时，同一个物理引脚出现在：

```text
背面看：  ...  P54   VCC   P55   GND   VCC   GND
                                          ↑最右端是 GND，不是 VCC
```

**如果按"正面记住的从左往右"去背面插，第 1、2 根就会落到 P10 / P11 那一端；
如果按"第 1 脚是 GND、第 2 脚是 VCC"去数，又容易整体错一位 —— 而这块板上 `GND, VCC, GND` 是连着的，错一位正好变成 5V 进 GND、GND 进 VCC = 反接。**

### 2.2 正确做法

1. **先正面朝上看清**：最左端是 `GND`，紧挨着右边是 `VCC`（第 2 根）。
2. **翻面前先用记号笔在背面（焊点面）对应位置做两个记号**：一个点 = GND，两个点 = VCC。
3. 翻过来插线时**只认记号**，不数位置。
4. 插完**拍照**。

> 更省事的替代：直接买**带丝印的排线**，或用标签纸在每根线上写明 `GND` / `5V`。

### 2.3 还有一层风险：`GND, VCC, GND` 连在一起

上排前三个脚是 `GND, VCC, GND`。
**在这三个脚之间整体错一位，就一定会把 5V 和 GND 对调。** 这是这块板结构上的"坑"。

## 3. 重新上电的排障流程（四段，按顺序做）

> 全程遵守：**每一步只增加一个变量；每步都有明确的"合格/不合格"判据。**

### 第 A 段 · 断电（此时不接 MCU）

| 步骤 | 动作 | 合格判据 | 不合格怎么办 |
| --- | --- | --- | --- |
| A1 | 认脚：正面看清 `GND`(第1) 与 `VCC`(第2)，背面做记号 | 记号位置明确 | 重做，别靠记忆 |
| A2 | 万用表通断档：以电池负极为基准，点每根针 | 只有 GND 脚响 | 若 VCC 也响 → 板/线有短路，停 |
| A3 | 断开一切负载，只留 MP1584 输入，上电 | `OUT+`↔`OUT−` = **4.95~5.10V** | >5.2V 或 <4.8V → 调或换模块 |
| A4 | 断电，量 `OUT+` ↔ `OUT−` | **不导通** | 导通 → 模块坏，换 |
| A5 | 通断档量 TB6612 `VCC`↔`GND`、编码器 `蓝`↔`黑` | **都不导通** | 导通 → 该件已损坏，换 |

### 第 B 段 · 量线（仍然不接 MCU）← **最关键的一步**

| 步骤 | 动作 | 合格判据 | 不合格怎么办 |
| --- | --- | --- | --- |
| B1 | 上电，**黑笔夹住"你打算接 MCU GND 的那根线"** | — | — |
| B2 | **红笔点"你打算接 MCU VCC 的那根线"** | 读数 **+5V** | **读到 −5V → 两根接反了，立刻对调** |
| B3 | 把两根线做**永久标记**：红线标签写 `5V`、黑线写 `GND` | 标记牢固 | 重做 |

> **这一步 10 秒完成，能挡住本次 90% 的死因。**

### 第 C 段 · 上电（接 MCU，但先限流）

| 步骤 | 动作 | 合格判据 | 不合格怎么办 |
| --- | --- | --- | --- |
| C1 | 在 5V 进 MCU 前**串 100Ω / 1W 电阻** | — | — |
| C2 | 上电，量 MCU 的 `VCC` 脚对 `GND` 脚 | 电压正常（不被拉到近 0） | 接近 0V → 有短路，**立刻断电**，别直连 |
| C3 | 摸芯片温度 | **微温** | 发烫 → 立刻断电，板子有问题 |
| C4 | 断电，去掉电阻，正式接 | — | — |
| C5 | 再次上电，摸温度 10 秒 | 微温 | 发烫 → 断电 |

### 第 D 段 · 逐个加负载

顺序：**MCU → 电位器/按键 → TB6612（不含电机动力）→ 编码器 → 电机红白线**。

每接一个：

1. 上电，量 5V 仍在 4.95–5.10V；
2. 摸 MCU 和该模块温度；
3. 异常 → **立刻断电，回退上一个接法**，不要带着故障继续加。

## 4. 现象 → 结论 速查表

| 现象 | 最可能原因 | 立刻做什么 |
| --- | --- | --- |
| 上电瞬间「啪」+ 冒烟 | 电源反接 / 过压 | **立刻断电**，不再上电；按第 A 段重新验电源 |
| 芯片空载发烫 | 芯片已损坏（漏电型） | 换板，别反复上电 |
| 量 `VCC` 对 `GND` 得到 **−5V** | 两根电源线接反 | 对调后重测，合格才插板 |
| 量 `VCC` 对 `GND` 得到 0V | 没供电 / 线没插实 / 模块坏 | 查线、查开关机、查 A3 |
| 5V 只有 4.5V 左右（带载） | 线阻大 / 杜邦线接触不良 / 负载过重 | 换 22AWG 线、换端子 |
| 设备反复重启 | 5V 被电机拉低（无 VM 电容） | VM 处加 100µF，电源线加粗 |
| 烧录时检测不到芯片 | 未冷启动 / TX/RX 未交叉 / 芯片坏 | 先做 A/B 段，再按烧录清单 |

## 5. 本次绝对不要再做的事

1. ❌ 不要"换个新板再照原样插一遍试试" —— 没解决方向问题，会再烧一块。
2. ❌ 不要按"从左数第几个"定位引脚。
3. ❌ 不要用杜邦线颜色判断正负。
4. ❌ 不要只量 MP1584 输出就认为"电源没问题" —— 要量**送到 MCU 的那两根线**。
5. ❌ 不要用"VCC↔GND 不导通"证明芯片没坏。
6. ❌ 芯片发烫时不要反复上电。

## 7. 下一步：先定案，再上保护

### 7.1 一次定案（免费，现在就能做）

**目的**：在烧掉第二块板之前，先确认"送到 MCU 的那两根线"到底是多少伏。

**做法**：

1. **把烧毁的 MCU 从电路里拔掉**（它已经没用了，但引脚要空出来）。
2. **其余接线一根都别动** —— TB6612、编码器、电位器、按键、MP1584、开关机，全部保持原样。
3. 长按开机，上电。
4. 万用表直流 20V 档，量**原来插进 MCU 的 `VCC` 与 `GND` 那两根线的末端**（不是量模块）。

| 读数 | 含义 | 下一步 |
| --- | --- | --- |
| **7.4 ~ 8.4V** | **确诊：7.4V 窜进了 5V 轨** | 顺着这两根线往回找，看它们实际接在哪个端子；改接到 MP1584 的 `OUT±` |
| **4.95 ~ 5.10V** | 电源这一路是对的 | 嫌疑转向别处：信号脚误接 7.4V、开关机瞬时尖峰、核心板本身坏件 |
| 0V | 线没接上 / 开关机没打开 | 先修通断电 |
| 波动、忽高忽低 | 接触不良 / 模块不稳 | 换端子、换模块 |

5. **再把每一根信号线对 GND 量一遍**（P54、P55、P37、P32、P33、P10、P11）。
   **任何一根超过 5.5V，就是那根接错了电源**，直接定位。

> 这一步不需要新板、不需要花钱，却是唯一能真正定案的动作。

### 7.2 保护主控的五层（从最有效到最省事）

> **先说清楚：保护只能保证"不再烧"，不能代替找根因。7.1 和 7.2 要同时做。**

#### 第 1 层（最推荐）：让 MCU 用**独立电源**

调试期间，**不要**把 MCU 的 VCC 接到项目 5V 轨上：

- 拔掉 MCU 的 VCC 那根杜邦线；
- 用一个 **USB 充电器 / 充电宝**，经一根 **USB 转 5V 的杜邦线**直接给 MCU 供电；
- **GND 仍然要和项目共地**（GND 那根保留）。

这样项目侧的 5V 轨无论出什么问题，都烧不到 MCU。等你确认信号都正常，再把 VCC 换回项目 5V。

> 配合一个 **USB 电流表**（约 ¥10–20，串在 USB 线上），能实时看到电压和电流 ——
> 正常空片只有几 mA；一上电就几百 mA，立刻拔。

#### 第 2 层：串联限流

| 元件 | 参数 | 作用 | 备注 |
| --- | --- | --- | --- |
| **PTC 自恢复保险丝** | 0.2A / 60V | 过流自动断开，冷却后自恢复 | 约 ¥1，**免焊接**（有现成带端子的） |
| 电阻 | **100Ω / 1W** | 短路时只有 50mA；正常压降 0.5–1.5V，STC8G 仍能跑 | **首次上电推荐**，最安全 |
| 电阻 | **47Ω / 1W** | 短路时约 100mA；压降 0.2–0.7V | 配第 3 层稳压管时用 |

**建议**：新板第一次上电串 **100Ω**；确认不短路、芯片微温后，换 **47Ω** 或 PTC 正式跑。

#### 第 3 层：过压箝位（可选，需要焊接）

在 MCU 的 `VCC` 与 `GND` 之间并一只 **5.6V / 1W 稳压管**（如 1N4735A，注意方向：**阴极接 VCC**），
串联电阻改用 **47Ω / 1W**：

```text
5V ──[47Ω]──┬── MCU VCC
            │
           ▼|  5.6V 稳压管（阴极朝上）
            │
GND ────────┴── MCU GND
```

- 输入正常 5V：稳压管不导通，不影响；
- 输入误接 7.4V：电流约 38mA，稳压管把电压钳在 **5.6V 左右**（电阻发热约 0.09W，稳压管约 0.21W，1W 都够）；
- 5.6V 仍略高于芯片 5.5V 极限，**不是完美保护**，但能把 8.4V 的致命冲击降到"大概率能活"。

> 这一步要焊，按你的偏好可以不装 —— 用第 1 层（独立供电）已经能挡住绝大多数风险。

#### 第 4 层：反接保护

串一只 **SS14 肖特基**（压降约 0.3V），接反只是不工作、不会烧。可与第 3 层叠加。

#### 第 5 层：分级上电 + 摸温度

顺序固定：**只接 MCU → 加电位器/按键 → 加 TB6612（先不接电机）→ 加编码器 → 最后接电机红白线**。
每加一个：量 5V、摸温度、看电流。异常立即断电回退。

### 7.3 第一夜的推荐顺序

1. **做 7.1 定案**（拆掉坏板，量线）→ 把结果记下来；
2. 按 7.1 的结果修好电源路径；
3. 新板到手后，按 7.2 的**第 1 层（独立 USB 供电）**+ **第 2 层（10Ω）**上电；
4. 裸板先烧录成功、串口有输出；
5. 再逐级接回负载，最后才接电机。

> 只要守住"MCU 先用自己的电源、项目电源单独验证"，就算项目侧还有问题，你也只会烧掉一个 ¥10 的模块，而不是每接一次就烧一块板。
