### 7.2 TB6612FNG 模块丝印（背面朝自己）

### 7.3 电机 JGB37-520 线序（6 根）

| 线色 | 功能 |
|------|------|
| 红 | 电机电源 + |
| 白 | 电机电源 −（与红对调即可反转） |
| 蓝 | 编码器电源 +（5V） |
| 黑 | 编码器电源 −（GND） |
| 黄 | 编码器 A 相（C1，电机一圈 11 脉冲） |
| 绿 | 编码器 B 相（C2） |

### 7.5 CH340 烧录接线（交叉接，TX↔RX）

| CH340 模块 | 接到单片机 | 说明 |
|-----------|-----------|------|
| TXD | **P3.0**（板**右侧丝印 RX**；或下排第 3 脚 P30） | 发送→接收，交叉 |
| RXD | **P3.1**（板**右侧丝印 TX**；或下排第 4 脚 P31） | 接收→发送，交叉 |
| GND | GND | 必须共地 |
| VCC | **不接** | 板子由电池供电时；模块跳线**选 5V**（3.3V 高电平对 5V 供电的 STC8G 偏临界） |

> **实测（2026-10-17）**：右侧 4 针中 **`TX` ↔ P31**、**`RX` ↔ P30**。即丝印写的是"芯片自己的收发脚"，所以接外部模块时**必须交叉**；按位置一一对齐会接错。

烧录步骤：STC-ISP 选 STC8G1K08 → 主频 24MHz → **不要**勾「P5.4/RST 用作复位脚」→ 点「下载」→ 提示「正在检测单片机」时给板子**断电再上电**（CH340 无自动冷启动）。

### 7.6 本次接线修正（2026-10-15）

- **电机大电流地回流**：加一根 **22AWG 硅胶线**，从**开关机模块 `OUT−` 直连 TB6612 的 `GND`**，使电机堵转电流直接回电池、不穿过 MP1584 模块，避免地弹与 5V 瞬降。
- **B 通道未用**：TB6612 的 **`BIN1`、`BIN2` 接 GND**，避免输入悬空；故 TB6612 实际用脚由 9 增至 **11**。
- **电机接口**：电机自带 PH2.0 母座 + 附赠公头线（6 根齐全），直接用它，SH1.0 端子线可不买。
- 上电前必做项与详细步骤见 `上电前检查与接线修正.md`。

## 八、采购避坑要点（重要）

1. **主控**：买**最小系统板**（芯片已焊 + 针脚引出），别买裸芯片；**别买 STC8G1K08A**（后缀带 A 引脚定义不同）。
2. **电机**：必须选**带编码器**版本；电压选 **6V**（不是 12V，12V 版在 7.4V 下转速打折无力）。
3. **万用表（最重要）**：MP1584 出厂默认输出不一定是 5V，**上电前必须用万用表调到 5.00V 再接 MCU**，否则可能烧 STC8G。
4. **电源线别用杜邦线**：单根只能过约 1A，电机堵转可达 2-3A；电池→驱动板这段必须用 **22AWG 硅胶线**。
5. **传感器线色**：电机到货后以实际线序为准，先确认再插 MCU。
6. **电池**：买**带引线**的 103450，且**不带保护板的单节**（本项目外接 2S 保护板）。
7. **电位器**：认准 **B10K**（线性），行程 45mm，**单联 3 脚**，别买成 A10K（对数）或双联 6 脚。
8. **充电板**：必须 **2S**（双节串联）+ **Type-C** 输入，别买 1S。
9. **保护板**：选 **2S**、电流 ≥5A、**带均衡**。
10. **轴承**：**内径 6mm 是硬指标**（套 Ø6 卷轴轴颈）；ZZ 铁盖防尘，别买开式。
11. **无铅焊锡**：熔点 217°C，烙铁设 **380-400°C**，每点 2-3 秒；烙铁头首次使用先镀锡。
12. **砂布不是普通纱布**：买**布基砂布**（背布可反复弯折），纸基砂纸拉几次就断。
13. **电解电容（可选）**：感性负载（电机）建议在 VM 处就近加 100µF/16V；本项目可不加——电池本身即大电容，TB6612 与 MP1584 板载已有电容，风险很低。
14. **USB-TTL 烧录器**：认准 **CH340**（CH340G / C / E / N 功能相同），要带 3.3V/5V 跳线并引出 TXD / RXD / GND；**避开 PL2303**（新版 Windows 下驱动易报错）。Win10/11 免驱（系统驱动库已内置 WCH `ch341ser`）；CH340 无自动冷启动，下载时需手动断电再上电。
